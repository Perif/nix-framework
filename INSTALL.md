# Installation and changes

See the [numbered guide index](docs/README.md) for all setup and reference documentation.

Choose one path:

1. **New installation:** follow [the five installation stages](docs/00-install.md).
   This erases the selected disk.
2. **Already installed:** [apply a configuration change](docs/install/06-customization.md)
   or [update the repository and dependencies](docs/install/26-upgrade.md).
3. **Installation interrupted:** follow [recovery](docs/install/28-recovery.md).
   Do not rerun `format`.

After installation, complete [first-boot verification](docs/install/05-first-boot.md).
