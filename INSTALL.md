# Installation and changes

Choose one path:

1. **New installation:** follow [the five installation stages](docs/INSTALL.md).
   This erases the selected disk.
2. **Already installed:** [apply a configuration change](docs/install/customization.md)
   or [update the repository and dependencies](docs/install/upgrade.md).
3. **Installation interrupted:** follow [recovery](docs/install/recovery.md).
   Do not rerun `format`.

After installation, complete [first-boot verification](docs/install/05-first-boot.md).
